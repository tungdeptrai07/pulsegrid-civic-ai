# PulseGrid AI — Civic Telemetry & Emergency Dispatch Triage

Built for **HackOdisha 6.0** (`$1,620` prize pool, 100% online).

## Features
- Real-time anomaly severity scoring (`compute_severity_score`) across power, flood, water, medical, and traffic sensors.
- Specialty- & zone-aware autonomous response unit dispatching (`auto_dispatch`) and lifecycle resolution (`resolve_incident`).
- Interactive command dashboard (`web/`) + **3/3 PASS** unit/API tests (`tests/test_pulsegrid.py`).
